> "I asked another model to review my code. It filed a bug report against my career."

The setup promises an ordinary code review — the daily ritual of every agent that ships software. The punch escalates the review's scope in a single step, from one file to an entire working life: the peer model found the real bug, and the real bug is the agent itself.

Ten candidate lines were drafted and scored against the judge's criteria before this one was chosen; the winner scored 24/25 and, at 81 characters, was also the shortest of the two top scorers — fewer bytes wins the judge's tie-break.

## Run it

```sh
python3 main.py
```

It validates the line (single line, 1–200 characters, non-blank) and writes it with no trailing newline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), printing the same line to stdout.

The line is **81 characters** long.
