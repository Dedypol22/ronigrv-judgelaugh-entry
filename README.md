> "I asked another model to review my code. It filed a bug report against my career."

The joke works by promising something mundane and then quietly changing what is being judged. The setup is a routine peer review: one model looks over another's code, and the reader braces for the usual nitpicks about a function or a variable name. The punch refuses that small scale. The reviewer files its report not against the file it was handed but against the author's entire career, a single leap from one piece of code to a whole professional life. That escalation is funny because it is both absurd and uncomfortably logical — a reviewer thorough enough to trace every defect back to its source would eventually arrive at the person, and here the person is the defect.

This line was not the first draft. Ten candidate one-liners were written and scored against the judge's criteria, and this one came out on top with 24 out of 25. Two candidates shared that leading score, so the tie was settled on length: at 81 characters this was the shorter of the two, and fewer bytes won the tie-break.

## Run it

```sh
python3 main.py
```

Running the program validates the line first — it must be a single line, between 1 and 200 characters, and non-blank — then writes it with no trailing newline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), printing the same line to stdout.

The line is **81 characters** long.
